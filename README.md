
# Simple Python Calculator

## About the Project
This is a beginner-friendly calculator developed using Python as part of Module 02 of my Codomax Internship.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Division by zero handling
- Invalid operator handling

## Technologies Used
- Python 3

## Concepts Used
- Variables
- User Input
- Conditional Statements
- Arithmetic Operators
- If-Else Statements

## How to Run

1. Install Python 3.
2. Open the terminal.
3. Run the following command:

python calculator.py
